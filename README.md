# Virginia Galindo de Benito | Portfolio

Portfolio web creado con React, TypeScript, Vite y Tailwind CSS. La página principal está en `/` y el Career Hub en `/hub`.

## Requisitos

- [Bun](https://bun.sh/)

## Desarrollo

```bash
bun install
bun run dev
```

Vite muestra la dirección local en la terminal (por defecto, `http://localhost:3000`).

## Comprobaciones y publicación

```bash
bun run lint
bun run build
bun run preview
```

La configuración del cliente Firebase se encuentra en `firebase-applet-config.json`.
